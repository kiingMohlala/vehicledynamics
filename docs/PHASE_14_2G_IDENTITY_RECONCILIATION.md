## 2. Contradiction explained

### Program brief / reference layer (NOT the plant that produced 5.36 s)

| Parameter | Value | Source |
|-----------|-------|--------|
| mass target | **1100 kg** | `reference_vehicle.py` `mass_target_kg`; `reality_reference.py` `build_hypercar_demonstrator(mass_kg=1100)` |
| mass est | 1120 kg | `reference_vehicle.py` |
| power | **750 kW** | `reference_vehicle.py` `power_kw`; `program_config.py` brief string; `reality_program.py` REQ + `build_hypercar_demonstrator(power_kw=750)` |

### Simulation plant used for 14.2D / 14.2E / 14.2F

| Parameter | Value |
|-----------|-------|
| mass | **1400 kg** |
| power | **280 kW** |

### Proof that 14.2E numbers belong only to 1400/280

| Configuration | 0–100 | 0–200 |
|---------------|-------|-------|
| **1400 kg / 280 kW (frozen_cfg)** | **5.36 s** | **19.77 s** |
| 1100 kg / 750 kW (brief) | 3.15 s | 7.32 s |
| 1100 kg / 280 kW | 4.51 s | 15.66 s |
| 1400 kg / 750 kW | 3.47 s | 9.36 s |

**Conclusion:** The recorded 14.2E results (5.36 / 19.77) were generated by the **1400 kg / 280 kW** `SimulationConfig`, not by the 1100 kg / 750 kW program brief.

14.2F did **not** invent a different vehicle than 14.2E. It audited the same plant 14.2E actually ran. The mismatch is between:

1. **Project brief / ReferenceVehicle** (1100 kg, 750 kW) — requirements / demonstration identity  
2. **Plant frozen_cfg** (1400 kg, 280 kW) — what `validation_14_2D/E` hard-coded into `Simulation`

Neither side was mutated by 14.2F. The provenance gap existed from 14.2D onward.

## 7. Final verdict

### **14.2F RECONCILED — VALID WITH LIMITATIONS**

**Why not INVALIDATED:**  
14.2F audited the same vehicle configuration that produced the 14.2E telemetry. Mass 1400 / power 280 in 14.2F matches `frozen_cfg()` in commit 8866ddb. Numbers reproduce with std 0.

**Why WITH LIMITATIONS:**  
The project brief and `ReferenceVehicle` still specify **1100 kg / 750 kW**, but that identity was **never wired** into the 14.2D/E simulation validators. Evidence validates the **1400 kg / 280 kW plant**, not the hypercar brief.

**Minimum correction required (for a future phase — not done here):**  
Bind `ReferenceVehicle` / `build_hypercar_demonstrator` parameters into `SimulationConfig` (or document permanently that 14.2 plant evidence is for the 1400/280 demonstrator only). Until then, any claim that “the 1100 kg 750 kW vehicle did 5.36 s” is a provenance error.
