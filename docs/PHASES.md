# Development Phases

- 2-DOF quarter-car model
- Skyhook / Groundhook / Hybrid controllers
- ISO 8608 road profiles
- Full validation suite

## Phase 3 – Braking System

- Thermal model + fade

- Independent validation suite
- Friction ellipse / utilization surfaces
