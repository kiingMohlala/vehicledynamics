# Combined-Slip Visualization Package

Generated by `vehicle_dynamics.tire.visualization`

## Expected Files

- `Fx_surface.png` – Longitudinal force Fx(κ, α)
- `Fy_surface.png` – Lateral force Fy(κ, α)
- `lambda_surface.png` – Saturation factor λ(κ, α)
- `utilization_surface.png` – Friction utilization
- `line_slices.png` – Pure longitudinal and pure lateral slices
- `surfaces.npz` – Raw numerical data

## Review Checklist

When inspecting the surfaces, look for:

- [ ] Smooth transition from linear region into saturation
- [ ] No discontinuities, ridges, or oscillations
- [ ] Symmetry about κ = 0 and α = 0 (where expected)
- [ ] Utilization approaches but does not exceed 1.0
- [ ] Increasing |κ| reduces available |Fy| (and vice-versa)
- [ ] λ decreases as combined force demand increases

If any of the above appear violated, investigate before integrating into BrakeSimulation.
